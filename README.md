# LineOcrSearch

鼠标停在屏幕文字上，就在指定文件夹里把这段话搜出来。Windows 10/11 x64，单 exe，免安装，全离线。

## 用法

1. 双击 `LineOcrSearch.exe`。首次启动会在旁边新建 `LineOcrSearchData\` 并释放 OCR 运行时与模型（约 21MB），之后不再重复。
2. 点「设置」，把搜索文件夹改到你放资料的地方。
3. 鼠标停在任意文字上约 0.5 秒，自动取词并搜索。
4. 结果双击用默认程序打开；`↑` `↓` 选中、`Enter` 打开、`Ctrl+C` 复制。长句按窗口宽度自动折行完整显示，拖动窗口大小即时重排。

输入框显示实际识别的整段文字，灰色部分表示搜索时没用上。可直接改，**多个关键词用空格隔开，全部命中才算**。

## 键盘与右键

| 操作 | 效果 |
|---|---|
| 输入框 `Enter` | 搜索 |
| 输入框 `↓` / `↑` | 跳到结果列表，选中第一条 / 最后一条 |
| `↓` / `↑` | 选中下一条 / 上一条（滚动跟随） |
| `PageUp` / `PageDown` | 列表翻页 |
| `Home` / `End` | 滚到顶 / 底 |
| `Enter` | 打开选中的文件 |
| `Esc` | 取消选中 |
| `Ctrl+C` | 复制命中行 + 路径 + 行号 |
| `Ctrl+Shift+C` | 只复制文件路径 |
| `Ctrl+F` | 回到搜索框并全选 |
| `F5` | 按当前关键词重搜 |
| `Tab` / `Shift+Tab` | 输入框 → 搜索 → 设置 → 结果列表 循环 |
| 右键点结果卡片 | 菜单：打开文件 / 打开所在文件夹 / 复制命中行 / 复制文件路径 / 复制「路径 · 第 N 行」 |

设置窗口：`Tab` 切换控件，`Enter` = 确定，`Esc` = 关闭。滚动条支持按住拖动，也可直接点轨道跳转。

## 设置

搜索文件夹 · 停留多久取词（0.2–1 秒）· 自动取词 · 取词后自动搜索 · 取词方式（智能 / 自动 / 总是 UIA / 总是识别图片）· 搜不到时逐字回溯 · 同时搜 Word/Excel · 前后文详略 · 结果条数 · 缓存上限（64–512 MB）。点「确定」保存。

缓存是「按文件夹预建」的：在设置里点「浏览」选完文件夹，或直接点「生成缓存」，就会立刻把该文件夹里支持的文件解析进缓存（已有且未改动的直接复用），建立过程中可以点「停止」。目录里没有支持的文件时不会产生缓存，并弹窗提示。缓存上限只管磁盘，超出后按写入时间从旧到新淘汰。

## 搜索范围

42 种文本后缀 + docx / docm / xlsx / xlsm 正文，以及 Word 97-2003（`.doc`）、Excel 97-2003（`.xls`）正文——老格式由程序自己解析 OLE 复合文档，**不依赖装 Office / LibreOffice**。文本单文件 ≤ 2 MB，Office ≤ 16 MB。

不支持：加密文档、Word 6.0/95 及更早、Excel 5.0/95、WPS 私有格式（`.wps` / `.et`）；这些仍只按文件名匹配。

## 构建

需要 zig 0.17.0。`build.bat` → `dist\LineOcrSearch.exe`（17.3MB，已内嵌 `res\` 下三个资源）；`tests\run_tests.bat` 跑测试。

源码树里 `res\` 只是打包输入，`LineOcrSearchData\` 是 exe 首次运行才生成的，两者不是一回事。

## 注意

数据都在 exe 旁的 `LineOcrSearchData\`：`config.ini`（设置）、`cache\`（文档提取缓存，默认上限 64MB，可在设置里改到 512MB）。截图、识别结果、日志都不落盘。
